# PowerTwin — Requirements Traceability Matrix

## 1. Overview

This matrix maps every platform requirement to its implementing module,
configuration, associated automated tests, validation evidence, known
limitations and official implementation status.

The matrix covers the repair packages PT-001 to PT-013 and the remediation
programme that followed them, which added the isolated Modbus TCP CIL gateway,
the historian durability and query work, the configuration and secrets hygiene
work and the CI/CD and release engineering work.

**How to read the "Test Result" column.** `PASS` means the named test is part
of the suite that the pipeline executes, and the suite was green on the last
full run. The authoritative, machine-checked evidence is the pipeline itself:
`pytest` with unraisable exceptions promoted to errors, on Python 3.12, 3.13
and 3.14. The **Coverage Policy** gate then proves that the safety-critical
domains remain above their enforced floors.

The companion documents are `docs/POWER_TWIN_FINAL_AUDIT_REPORT.md`,
`docs/POWER_TWIN_KNOWN_LIMITATIONS.md` and
`docs/POWER_TWIN_IMPLEMENTATION_STATUS.md`.
